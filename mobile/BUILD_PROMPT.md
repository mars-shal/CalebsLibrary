## C. Global production rules (apply to every phase, no exceptions)

- G1 Convex cost: NO `collect()`-all on mobile paths; paginated indexed queries only; 12h diff sync (insert/patch/delete by `by_drive_id`); `metrics.bump` delta clamped ±1 + 5s throttle; `shortLink.create` host-allowlisted + rate-limited; `trends.record` per commit + throttled; `pruneStale` fixed (score<0.01 or age>180d).
- G2 Secrets/PII: Drive key + passphrase server-side only (`npx convex env set`); contributor email NEVER rendered (anonymized handle + consent); passphrase in SecureStore; signed short-lived download URLs (never stored `?key=`); `decisions` audit log on every moderation action.
- G3 No fakes: no hash-stat seed as truth (real metrics overlay), no `reads*187`, no `sum/12`, no mock shelves, no fake pager, no dead Report, no disabled AI button in v1, no hardcoded "since 2023"/"three thousand".
- G4 Mobile correctness: preserve stack state (never full-remount like web `:key=fullPath`); async theme init (never render side-effects); drop dead `parents` from projections; NO global `*` CSS transition port; label ALL icon buttons (web had only 4 aria-labels).
- G5 UI contract: `SafeGlass` is the ONLY glass call-site with `isGlassEffectAPIAvailable()+isLiquidGlassAvailable()+!reduceTransparency` guards; glass on chrome only (never body text/lists/cards/PDF); fallback matrix honored; icons animate ≤250ms on interaction, never looping in lists; Reduce Motion/low-power/<3GB RAM disable decor; 44pt targets; AA contrast.
- G6 Budgets: TTI <2s cached/<4s cold; 60fps 2k rows (FlashList windowSize 5); PDF cached open <1s; size <60MB; RAM <250MB scroll; crash-free >99.5%.
- G7 Verification per phase: `tsc` clean, lint clean, exit criteria demoed (online + offline + dark + large-font), outbox/queue paths exercised where applicable.
